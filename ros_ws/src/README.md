# FIV ROS 2 packages

Add a ROS 2 package directory here for each FIV capability. Initial targets:

- `fiv_bringup`
- `fiv_gap_follow`
- `fiv_interfaces` (only if custom interfaces are needed)
- `fiv_teleop` (optional)

See [the architecture guide](../../docs/architecture.md) before defining
topic names or package dependencies.
